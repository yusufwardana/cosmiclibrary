# 📐 CosmicLib Blueprints

Direktori ini berisi cetak biru (blueprints) teknis untuk CosmicLib Engine. Dokumen di sini mendefinisikan skema mentah yang akan diterjemahkan menjadi kode program di fase pengembangan berikutnya.

## Berkas yang Tersedia
- **`database_schema.sql`**: Skema database MySQL mentah yang memodelkan manajemen pengguna, peran, anggota, buku, sirkulasi (peminjaman), denda, dan setelan sistem.

## Cara Menggunakan Blueprint
Cetak biru ini dirancang agar dapat diimpor langsung ke alat perancang database (seperti MySQL Workbench, dbdiagram.io, atau TablePlus) untuk menghasilkan visualisasi diagram hubungan entitas (ERD), atau dapat digunakan oleh AI assistants untuk menyusun migrasi Laravel dengan presisi 100%.
