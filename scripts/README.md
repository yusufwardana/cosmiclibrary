# 🛠️ CosmicLib Scripts

Direktori ini dirancang untuk menyimpan skrip otomatisasi pembantu pengembangan, migrasi, pencadangan (backup), dan penyebaran (deployment).

## Contoh Skrip Jangka Panjang
- **`backup-db.sh`**: Skrip shell untuk mencadangkan database MySQL lokal/cPanel secara rutin.
- **`deploy-cpanel.sh`**: Skrip otomatisasi untuk melakukan transfer file aman via SSH/FTP ke server hosting.
- **`clear-cache.sh`**: Skrip cepat untuk menghapus cache Laravel dan Vite secara serentak.
