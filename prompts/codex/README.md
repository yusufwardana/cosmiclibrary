# 🧠 Codex Prompt Guide

Direktori ini menyimpan panduan rekayasa instruksi untuk asisten inline autocomplete seperti **GitHub Copilot** atau **OpenAI Codex**.

## Konfigurasi Kunci
- Gunakan blok komentar DocBlock yang mendetail di setiap method untuk memandu Copilot menyusun fungsionalitas dengan benar.
- Pertahankan struktur routing RESTful.
- Pastikan kueri Eloquent meminimalkan N+1 dengan `with()`.
