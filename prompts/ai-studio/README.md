# 🧠 AI Studio Prompt Guide

Direktori ini menyimpan pedoman rekayasa instruksi khusus untuk asisten **Google AI Studio Build** (Gemini-powered coder).

## Instruksi Workspace
- Selalu jalankan `compile_applet` atau `lint_applet` untuk memverifikasi perubahan visual pada React dashboard.
- Pastikan server web diikat ke port `3000` dengan host `0.0.0.0` jika membuat backend kustom.
- Hindari pembuatan input manual API key pada visual UI karena AI Studio sudah mengelolanya secara aman melalui panel Secrets.
