# 🧠 Cline Prompt Guide

Direktori ini menyimpan aturan operasional khusus untuk asisten otonom **Cline** yang menggunakan model berbasis command line.

## Batasan Operasi
- Selalu baca file `.clinerules` sebelum melakukan edit kode.
- Jangan pernah menghapus dokumentasi berangka (`00_` hingga `20_`) di dalam folder `docs/`.
- Prioritaskan performa kueri dan kebersihan berkas cadangan (backup).
